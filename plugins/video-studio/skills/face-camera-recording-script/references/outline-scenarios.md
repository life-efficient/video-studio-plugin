# Outline workflow checks

- Positive: “Write a presenter script and structure its Studio outline around problem, evidence, and implications.” Use this skill, keep the spoken copy continuous, and save only metadata through the beat tool.
- Negative: “Render this existing video with new captions.” Use the video editing workflow, without rewriting its script or outline.
- Adjacent: “Revise the beat mentioned in my script comment.” Read the current Studio script and unresolved feedback, then change the requested beat. Do not treat historical or resolved feedback as a new rewrite request.
- Revision conflict: A colleague edits the script between read and update. The stale outline update must fail; reread the current text and reconcile its anchors before retrying.
- Ambiguous anchor: A proposed start quote appears twice. Choose a longer unique exact quote. Never guess an offset or insert a spoken heading to force a match.
- Metadata-only check: Save titles and anchors, then read back. The spoken script must remain byte-for-byte unchanged, the outline must resolve, and history must retain the prior outline.
